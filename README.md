## 使用顺序

先按XLSX的筛选结论、国家、方向和优先级缩小范围，再核对季节/时长、必需技能及JD的授权条件。通用人才池和博士限定岗位单独保留。对照官方链接查看当前状态，再选对应D1-D5简历。

需要恢复CMU Handshake独立会话；其余缺项统一留在《待确认事项》。目前不需要逐项回复。

本轮没有投递、发送消息、上传简历、推送GitHub，或安装/运行评估的求职工具；没有建立持续自动化。
